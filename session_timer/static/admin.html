Quick help

  • The URL is everything. Anyone with the session URL can view or edit; there is no login. Share the display page via the QR code and keep the admin URL to yourself.
  • Times are times of day (24-hour HH:MM). The session follows one timezone — fixed by the first admin visit; ☰ → "Set timezone to this browser" on a device in the right room if it is wrong. At that zone's midnight the day resets, so the same schedule runs again tomorrow. Events may be scheduled up to 47:59 (hours of 24 or later are the next day's early hours and never trigger on today's run).
  • +/- nudge by a minute. With "delay later events" checked, they cascade to everything starting after (shown in the Gap column; negative = overlap, not blocked). The now button sets an event's start to the current minute (same cascade rule) — "this talk just started".
  • Event now ▾ creates a talk starting at the current minute — pick a preset duration (3–60 min) or Custom.
  • Clocks: the toolbar time and the display's small corner clock both show the session's own timezone (the ☰ menu's timezone line names it); toggle the display's with ⏱.
  • Embedding: /SESSION_NAME/iframe is a bare progress-bar-only view (no countdown) for embedding into other pages.
  • Manual edits delay later events (☰ menu, off by default): when checked, typing a new start or duration shifts every later event by the same amount — for big re-timings where clicking +/− many times is impractical.
  • Everything syncs live across all open panels. If someone else edits while you do, you'll be asked to refresh. Displays do not need a correct clock — time comes from the server.
  • Display colors: green, yellow at ≤25% left, red at ≤15%; after expiry it flashes for 5 minutes, then idles at a grey 00:00.
  • On the display: ⛶ fullscreen; +/− text size (per display browser, mirrored in the preview strip); ☾/☀ room dimming, synced to every panel — handy from the admin screen when the room lights go down.
  • Data is memory-only. Lost on server restart unless the operator enabled snapshots, and idle sessions expire after 31 days — download a CSV to be safe.

Otherwise: poke at it — it's meant to be explored.
